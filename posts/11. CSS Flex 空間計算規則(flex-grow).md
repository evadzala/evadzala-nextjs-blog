flex-grow 為伸展值，分配剩餘的空間

在一個外部容器上加上 `display: flex;`，內部則補上 `flex: 1;` 預期會得到如下的結果：三個等比切分的內元素（三個寬度各佔 33%）。

```html
<div class="flex">
  <div class="item flex-1"></div>
  <div class="item flex-1"></div>
  <div class="item flex-1"></div>
</div>
```

```css
.flex {
  display: flex;
  height: 300px;
  padding: 15px;
  background-color: #61a0f8;
}

.item {
  // 無影響的屬性
  height: 100%;
  background-color: #f08bc3;
  display: flex;
  justify-content: center;
  align-items: center;
  color: white;
  border: 1px solid white;
  box-sizing: border-box;
}

.flex-1 {
  flex: 1;
}
```

若如果只有兩個內元素且分為flex: 1;及flex: 2;
則空間比例會變成1:2

```html
<div class="flex">
  <div class="item flex-1"></div>
  <div class="item flex-2"></div>
</div>
```

```css
.flex {
  display: flex;
  height: 300px;
  padding: 15px;
  background-color: #61a0f8;
}

.item {
  // 無影響的屬性
  height: 100%;
  background-color: #f08bc3;
  display: flex;
  justify-content: center;
  align-items: center;
  color: white;
  border: 1px solid white;
  box-sizing: border-box;
}

.flex-1 {
  flex: 1;
}

.flex-2 {
  flex: 2;
}
```
