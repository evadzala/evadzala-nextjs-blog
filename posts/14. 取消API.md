`AbortController` 是一個內建的 Web API，讓我們可以透過 `abort()` 方法取消 `fetch()` 或 `Axios` 請求。

基本用法:

```tsx
import axios from "axios";

const controller = new AbortController(); // 建立一個取消控制器
const signal = controller.signal; // 取得 signal 來傳遞給請求

axios
  .get("https://api.example.com/data", { signal })
  .then((response) => console.log(response.data))
  .catch((error) => {
    if (axios.isCancel(error)) {
      console.log("⛔ 請求已被取消");
    } else {
      console.error("❌ 其他錯誤:", error);
    }
  });

// 5 秒後自動取消請求
setTimeout(() => {
  controller.abort(); // 取消請求
  console.log("⏳ API 超時，自動取消");
}, 5000);
```

- `controller.abort()` 會發送取消信號，導致請求被中止。
- `axios.isCancel(error)` 可用來判斷錯誤是否為取消請求造成的。

頁面切換時取消 API:

```tsx
import { onUnmounted } from "vue";

const controller = new AbortController();

axios
  .get("/user-data", { signal: controller.signal })
  .then((res) => console.log(res.data))
  .catch((error) => console.log("API 請求已被取消"));

onUnmounted(() => controller.abort()); // 當組件卸載時，取消 API
```

設定 API 超時機制:

```tsx
const fetchData = async (url: string, timeout = 5000) => {
  const controller = new AbortController();
  const signal = controller.signal;

  // 設定超時取消
  const timeoutId = setTimeout(() => controller.abort(), timeout);

  try {
    const response = await axios.get(url, { signal });
    return response.data;
  } catch (error) {
    if (axios.isCancel(error)) {
      console.log("⛔ API 請求超時，已取消");
    } else {
      console.error("❌ 其他錯誤:", error);
    }
  } finally {
    clearTimeout(timeoutId); // 清除計時器，避免記憶體浪費
  }
};

// 使用函式
fetchData("https://api.example.com/data");
```

防止多次請求:

```tsx
let searchController: AbortController | null = null;

const fetchSearchResults = async (query: string) => {
  if (searchController) searchController.abort(); // 取消前一個請求
  searchController = new AbortController();

  try {
    const res = await axios.get(`/search?q=${query}`, {
      signal: searchController.signal,
    });
    console.log("搜尋結果:", res.data);
  } catch (error) {
    if (axios.isCancel(error)) console.log("⛔ 舊請求已取消");
  }
};
```

用處:

- 重複請求時取消前一次請求。
- 在 **組件卸載（Vue、React）** 時，取消 API 避免錯誤。
- 設置 **API 超時機制**，避免後端無回應時 UI 卡住。
- 可用於 **防抖（debounce）搜尋**、**頁面切換**、**API 超時控制** 等場景。
